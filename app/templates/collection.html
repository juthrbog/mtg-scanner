Search tips

A bare word looks in the card's name, type, set and keywords. Add a prefix to search one field:

  • t:creature — type line, so t:dragon or t:legendary
  • s:mbs — set name or code
  • kw:flying — abilities, from Scryfall's keyword list
  • o:draw — rules text (kept out of bare search; it matches almost everything)

Combine freely — every term must match. "exact phrase" in quotes, and - excludes: t:creature kw:flying -kw:defender.
